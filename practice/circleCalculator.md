# Circle Calculator

## Summary
 - Take in a radius from the user (make sure to use std::cin!)
 - Calculate the area of a circle from this radius (recall that the area of a circle is A = pi * r^2)
 - Use 3.14159 for pi

 ## Example Program Output
 Note: 13.4 was an input from the user
 ```text
 === Circle Calculator ===
 Radius? 13.4
 Area of Circle: 564.104
 ```
